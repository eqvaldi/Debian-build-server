# Debian-build-server-V4
automated build scripts for a Debian based distros for server env.

# Usage

1. Clone this repository: git clone https://github.com/eqvaldi/Debian-build-server.git

2. cd Debian-build-server/

3. Run: bash ./files.sh

4. Then run: bash ./build.sh (As sudo)
